\# Python RAG Asistanı!\[Tests](https://img.shields.io/badge/tests-8%20passed-brightgreen)!\[Python](https://img.shields.io/badge/python-3.11%2B-blue)!\[License](https://img.shields.io/badge/license-MIT-green)Microsoft Foundry Local kullanılarak internete bağlanmadan, tamamen yerel çalışan bir RAG (Retrieval-Augmented Generation) chatbot uygulaması. Python programlama dili hakkındaki sorulara, önceden yüklenmiş teknik dökümanlardan doğru bilgi bularak cevap verir.\## Özellikler\- \*\*Tamamen yerel çalışır\*\* — internet bağlantısı veya bulut API'si gerektirmez\- \*\*Hibrit arama\*\* — anlamsal (embedding) arama ile anahtar kelime eşleşmesini birleştirir\- \*\*Extractive yaklaşım\*\* — halüsinasyon riskini ortadan kaldırmak için kaynak paragrafı doğrudan sunar\- \*\*Web arayüzü\*\* — Flask tabanlı, kullanıcı dostu sohbet ekranı\- \*\*Benzerlik eşiği\*\* — alakasız sorularda "bilmiyorum" diyerek uydurma bilgi vermez\- \*\*Çoklu tur konuşma\*\* — önceki soruları hatırlayarak bağlamsal takip sorularını anlayabilir (ör. "peki ya liste?")\- \*\*Sohbeti dışa aktarma\*\* — konuşmayı .txt dosyası olarak indirebilme\- \*\*Kullanım istatistikleri\*\* — `/stats` endpoint'i ile toplam soru, cevaplanan ve bulunamayan soru sayılarını görüntüleme\- \*\*Log tutma\*\* — tüm sorular, skorlar ve kaynaklar `logs/app.log` dosyasına kaydedilir\- \*\*Merkezi ayar yönetimi\*\* — tüm yapılandırma değerleri `config.py` dosyasında toplanmıştır\- \*\*Health check\*\* — `/health` endpoint'i ile sistemin (embedding modeli, veritabanı) çalışır durumda olup olmadığını kontrol etme\- \*\*Girdi doğrulama\*\* — bozuk istekler, geçersiz formatlar ve aşırı uzun sorular güvenli şekilde reddedilir\- \*\*Quiz Modu\*\* — kullanıcıya döküman içeriğinden rastgele konular sorarak kendi kendine öğrenme testi yapma imkanı sunar\- \*\*Önbellekleme (cache)\*\* — tekrar sorulan sorular anında önbellekten cevaplanır, gereksiz hesaplama yapılmaz\- \*\*Görsel güven çubuğu\*\* — benzerlik skoru renkli bir çubukla (yeşil/sarı/kırmızı) görselleştirilir\- \*\*Geri bildirim sistemi\*\* — kullanıcılar cevapları 👍/👎 ile değerlendirebilir\## MimariKullanıcı Sorusu|vEmbedding Modeli (qwen3-embedding-0.6b)|vSQLite Veritabanı (rag.db) — Kosinüs Benzerliği + Anahtar Kelime Eşleşmesi|vEn Alakalı Paragraf --> Kullanıcıya Sunulur\## Kurulum\### Gereksinimler\- Python 3.11+\- \[Microsoft Foundry Local](https://github.com/microsoft/Foundry-Local) (`winget install Microsoft.FoundryLocal`)\### Adımlar```bashpip install -r requirements.txt```\## Kullanım```bashpython app.py```Sunucu başladıktan sonra tarayıcıda `http://localhost:5000` adresine gidin.\## Proje Yapısırag-projesi/├── app.py #
